# Sahraflix

Android TV IPTV application built with Kotlin, Jetpack Compose for TV, Media3, Room, Paging, and Hilt.

## Package layout

- `data`: persistence, remote APIs, and repository implementations
- `domain`: business models, contracts, and use cases
- `presentation`: Compose TV screens, state, navigation, and theme
- `player`: Media3 playback, subtitles, and track selection
- `di`: Hilt dependency providers
